# Требования к компонентам приложения

## Компонент FlashCard

### Текущий функционал

1. **Отображение карточки**
   - Карточка отображает польское слово на лицевой стороне
   - При клике карточка переворачивается и показывает русский перевод
   - Отображаются примеры использования слова (если есть)
   - Карточка имеет анимацию переворота

2. **Режимы обучения**
   - Поддерживает два режима: "pl-to-ru" (польский → русский) и "ru-to-pl" (русский → польский)
   - В зависимости от режима отображаются соответствующие кнопки для отметки уровня знания

3. **Управление уровнем знания**
   - Уровень 0: Не знаю (knowsPlToRu: false, knowsRuToPl: false)
   - Уровень 1: Знаю PL→RU (knowsPlToRu: true, knowsRuToPl: false)
   - Уровень 2: Знаю оба направления (knowsPlToRu: true, knowsRuToPl: true)
   - Кнопки для установки уровня отображаются только после переворота карточки

4. **Навигация**
   - После установки уровня автоматически переходит к следующей карточке
   - Отображается текущий уровень слова

### Новый функционал

1. **Удаление категории из карточки**
   - Категория (category) больше не отображается на карточке в режиме изучения
   - Категория остается в данных, но скрыта в UI карточки

2. **Свайпы для управления статусом (touch-события)**
   - Свайп влево = "знаю" - устанавливает текущий уровень изучения в зависимости от режима:
     - В режиме "pl-to-ru": устанавливает knowsPlToRu = true
     - В режиме "ru-to-pl": устанавливает knowsRuToPl = true
   - Свайп вправо = "не знаю" - сбрасывает текущий уровень изучения:
     - В режиме "pl-to-ru": устанавливает knowsPlToRu = false
     - В режиме "ru-to-pl": устанавливает knowsRuToPl = false
   - Свайпы работают только когда карточка перевернута (isFlipped = true)
   - Минимальное расстояние свайпа: 50px
   - Поддержка только touch-событий (мобильные устройства)

3. **Статус "требует проверки" (needsReview)**
   - Кнопка для переключения статуса needsReview отображается после переворота карточки
   - Визуальная индикация статуса: желтый баннер "⚠️ Требует проверки" над карточкой, если needsReview = true
   - Кнопка меняет цвет в зависимости от статуса:
     - Активный статус: желтый фон (bg-yellow-500)
     - Неактивный статус: серый фон (bg-gray-300)

4. **Кнопка "Пропустить"**
   - Кнопка "Пропустить" позволяет перейти к следующей карточке без изменения статуса знания
   - Отображается после переворота карточки
   - Оранжевый цвет (bg-orange-500)

### Тестовые сценарии

1. **Свайпы**
   - Свайп влево в режиме "pl-to-ru" должен установить knowsPlToRu = true
   - Свайп вправо в режиме "pl-to-ru" должен установить knowsPlToRu = false
   - Свайп влево в режиме "ru-to-pl" должен установить knowsRuToPl = true
   - Свайп вправо в режиме "ru-to-pl" должен установить knowsRuToPl = false
   - Свайпы не должны работать, когда карточка не перевернута
   - Свайпы должны игнорироваться, если расстояние меньше 50px

2. **Статус needsReview**
   - Клик по кнопке "Требует проверки" должен переключать статус needsReview
   - Визуальная индикация должна отображаться только когда needsReview = true
   - Статус должен сохраняться в базе данных

3. **Кнопка "Пропустить"**
   - Клик по кнопке "Пропустить" должен перейти к следующей карточке без изменения статуса
   - Статус знания слова не должен изменяться

4. **Категория**
   - Категория не должна отображаться на карточке

## Компонент WordList

### Текущий функционал

1. **Отображение списка слов**
   - Отображает все слова в виде списка
   - Показывает польское слово, русский перевод, примеры, категорию
   - Отображает текущий уровень знания каждого слова

2. **Фильтрация по уровню знания**
   - Фильтр по уровню 0, 1, 2
   - Можно выбрать несколько уровней одновременно
   - Показывает количество отфильтрованных слов

3. **Сортировка**
   - По уровню знания
   - По дате последнего просмотра
   - Возможность изменения порядка (по возрастанию/убыванию)

4. **Резервное копирование**
   - Экспорт данных в JSON файл
   - Импорт данных из JSON файла

5. **Запуск обучения**
   - Кнопка "Начать изучение" запускает режим обучения

### Новый функционал

1. **Фильтры по уровню языка (CEFR)**
   - Фильтр по уровням: A1, A2, B1, B2, C1, C2
   - Можно выбрать несколько уровней одновременно
   - Слова без уровня языка исключаются из результатов фильтрации
   - Фильтр работает совместно с фильтром по уровню знания

2. **Статус "требует проверки" (needsReview)**
   - Визуальная индикация в списке: желтый бейдж "⚠️ Требует проверки" для слов с needsReview = true
   - Кнопка для переключения статуса needsReview для каждого слова
   - Кнопка меняет цвет в зависимости от статуса

3. **Отображение уровня языка**
   - Уровень языка (A1-C2) отображается как синий бейдж в списке слов

4. **Применение фильтров при запуске обучения**
   - При нажатии "Начать изучение" передаются активные фильтры (по уровню знания и уровню языка)
   - Фильтры применяются к словам перед запуском режима обучения
   - Если после применения фильтров нет слов, показывается предупреждение

### Тестовые сценарии

1. **Фильтры по уровню языка**
   - Фильтр должен показывать только слова с выбранными уровнями языка
   - Слова без уровня должны исключаться при активном фильтре
   - Комбинация фильтров по уровню знания и уровню языка должна работать корректно

2. **Статус needsReview в списке**
   - Визуальная индикация должна отображаться для слов с needsReview = true
   - Клик по кнопке должен переключать статус
   - Статус должен сохраняться в базе данных

3. **Применение фильтров при обучении**
   - При запуске обучения должны применяться активные фильтры
   - Если нет слов после фильтрации, должно показываться предупреждение
   - Слова должны перемешиваться после применения фильтров

## Компонент WordForm

### Текущий функционал

1. **Форма добавления/редактирования слова**
   - Поля: польское слово, русский перевод, примеры (PL и RU), категория
   - Валидация обязательных полей
   - Сохранение слова в базу данных

### Тестовые сценарии

1. **Валидация формы**
   - Поля "польское слово" и "русский перевод" обязательны
   - Форма не должна отправляться без обязательных полей
