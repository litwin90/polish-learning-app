# Общие требования к приложению

## Обзор

Приложение для изучения польского языка с использованием карточек (flashcards). Подготовка к экзамену TELC B1.

## Основной функционал

### 1. Управление словами

1.1. **Хранение слов**
- Слова хранятся в IndexedDB (Dexie)
- Каждое слово содержит:
  - id (уникальный идентификатор)
  - polish (польское слово)
  - russian (русский перевод)
  - examples (примеры использования на обоих языках)
  - category (категория, опционально)
  - level (уровень CEFR: A1, A2, B1, B2, C1, C2, опционально)
  - knowsPlToRu (знаю польский → русский)
  - knowsRuToPl (знаю русский → польский)
  - needsReview (требует проверки, опционально)
  - lastReviewed (дата последнего просмотра)
  - createdAt (дата создания)

1.2. **Инициализация данных**
- При первом запуске загружаются данные из WORDS.json
- При изменении версии данных автоматически обновляется база данных
- Версия данных хранится в metadata

1.3. **Резервное копирование**
- Экспорт всех слов с прогрессом в JSON файл
- Импорт слов из JSON файла
- Автоматическое инкрементирование patch версии при экспорте

### 2. Режимы обучения

2.1. **Режим "pl-to-ru" (польский → русский)**
- Показывается польское слово
- После переворота показывается русский перевод
- Можно отметить: знаю PL→RU или не знаю

2.2. **Режим "ru-to-pl" (русский → польский)**
- Показывается русское слово
- После переворота показывается польский перевод
- Можно отметить: знаю RU→PL или не знаю

2.3. **Уровни знания**
- Уровень 0: Не знаю (knowsPlToRu: false, knowsRuToPl: false)
- Уровень 1: Знаю PL→RU (knowsPlToRu: true, knowsRuToPl: false)
- Уровень 2: Знаю оба направления (knowsPlToRu: true, knowsRuToPl: true)

### 3. Управление статусом слов

3.1. **Статус "требует проверки" (needsReview)**
- Позволяет пометить слова, которые вызывают вопросы к корректности
- Можно переключать статус в режиме обучения и в списке слов
- Визуальная индикация: желтый баннер/бейдж
- Статус сохраняется в базе данных

3.2. **Обновление статуса знания**
- При установке уровня знания автоматически обновляется lastReviewed
- Прогресс сохраняется в IndexedDB
- Статистика обновляется в реальном времени

### 4. Фильтрация и сортировка

4.1. **Фильтры по уровню знания**
- Фильтр по уровню 0, 1, 2
- Можно выбрать несколько уровней одновременно
- Применяется к списку слов и при запуске обучения

4.2. **Фильтры по уровню языка (CEFR)**
- Фильтр по уровням: A1, A2, B1, B2, C1, C2
- Можно выбрать несколько уровней одновременно
- Слова без уровня исключаются при активном фильтре
- Применяется к списку слов и при запуске обучения

4.3. **Сортировка**
- По уровню знания
- По дате последнего просмотра
- Порядок: по возрастанию/убыванию

4.4. **Применение фильтров при обучении**
- При запуске обучения применяются все активные фильтры
- Слова перемешиваются после применения фильтров
- Если нет слов после фильтрации, показывается предупреждение

### 5. Интерактивность

5.1. **Свайпы для карточек (touch-события)**
- Свайп влево = "знаю" (устанавливает текущий уровень изучения)
- Свайп вправо = "не знаю" (сбрасывает текущий уровень изучения)
- Работают только когда карточка перевернута
- Минимальное расстояние: 50px
- Только для мобильных устройств (touch-события)

5.2. **Кнопка "Пропустить"**
- Позволяет перейти к следующей карточке без изменения статуса
- Доступна в режиме обучения после переворота карточки

5.3. **Переворот карточки**
- Клик по карточке переворачивает ее
- Анимация переворота (3D эффект)

### 6. Статистика

6.1. **Отображение статистики**
- Всего слов
- Количество слов по уровням (0, 1, 2)
- Количество слов, просмотренных сегодня

6.2. **Обновление статистики**
- Статистика обновляется автоматически при изменении прогресса
- Обновляется при возврате из режима обучения

### 7. Интерфейс

7.1. **Главный экран**
- Статистика
- Выбор режима обучения (pl-to-ru / ru-to-pl)
- Переход к списку слов

7.2. **Список слов**
- Отображение всех слов с фильтрацией и сортировкой
- Кнопки для управления статусом needsReview
- Кнопка "Начать изучение" с применением фильтров

7.3. **Режим обучения**
- Карточка с польским/русским словом
- Кнопки для установки уровня знания
- Кнопка "Пропустить"
- Кнопка для переключения needsReview
- Индикация текущей карточки (N из M)

### 8. Технические требования

8.1. **База данных**
- IndexedDB через Dexie
- Версионирование схемы
- Миграции при обновлении

8.2. **Производительность**
- Использование useMemo для фильтрации и сортировки
- Оптимизация обновлений состояния

8.3. **Валидация данных**
- Валидация при импорте данных
- Проверка типов полей
- Обработка ошибок

### 9. Правила обновления требований

9.1. **Обязательное обновление требований**
- При любых изменениях функциональности необходимо обновлять соответствующие файлы требований
- Требования хранятся в файлах REQUIREMENTS.md в соответствующих директориях:
  - `src/components/REQUIREMENTS.md` - требования к компонентам
  - `src/utils/REQUIREMENTS.md` - требования к утилитам и хранилищу
  - `src/REQUIREMENTS.md` - общие требования к приложению

9.2. **Формат требований**
- Описание текущего функционала
- Описание нового функционала
- Тестовые сценарии для каждого функционала
- Формат должен быть подходящим для написания тестов

9.3. **Синхронизация**
- Все изменения в коде должны быть отражены в требованиях
- При добавлении новой функции необходимо добавить описание и тестовые сценарии
- При изменении существующей функции необходимо обновить описание
