# 🇵🇱 Приложение для изучения польского языка

Веб-приложение для изучения польских слов с помощью карточек (flashcards).

## 🎯 Возможности

- 📚 **Управление словами**: Добавление, редактирование и удаление слов
- 🎴 **Карточки для изучения**: Интерактивные карточки с переворотом
- 📊 **Отслеживание прогресса**: Отметка сложности слов (легко/средне/сложно)
- 💾 **Локальное хранилище**: Все слова сохраняются в браузере (LocalStorage)
- 📥 **Экспорт данных**: Скачивание резервной копии в формате JSON
- 📤 **Импорт данных**: Загрузка слов из JSON файла
- 📱 **Адаптивный дизайн**: Оптимизировано для мобильных устройств с Tailwind CSS
- 🎨 **Современный UI**: Красивый градиентный дизайн с плавными анимациями

## 💾 Сохранение данных

### LocalStorage (текущее решение)

Приложение использует **LocalStorage браузера** для сохранения данных. Это означает:

✅ **Преимущества:**
- Данные сохраняются между сессиями в том же браузере
- Не требуется сервер или регистрация
- Работает полностью офлайн
- Быстрый доступ к данным

⚠️ **Ограничения:**
- Данные не синхронизируются между устройствами
- Данные могут быть потеряны при очистке браузера
- Данные привязаны к конкретному браузеру

### Решение: Экспорт/Импорт

Для решения проблемы синхронизации между устройствами добавлены функции:

- **📥 Экспорт**: Скачайте резервную копию всех слов в JSON файл
- **📤 Импорт**: Загрузите слова из JSON файла на другом устройстве
- **🔄 Резервное копирование**: Регулярно экспортируйте данные для безопасности

### Как использовать:

1. **Экспорт данных:**
   - Нажмите кнопку "📥 Экспорт" в разделе "Резервное копирование"
   - Файл будет скачан с именем `polish-words-backup-YYYY-MM-DD.json`

2. **Импорт данных:**
   - Нажмите кнопку "📤 Импорт"
   - Выберите JSON файл с сохраненными словами
   - Новые слова будут добавлены к существующим (дубликаты по ID не добавляются)

3. **Перенос на другое устройство:**
   - Экспортируйте данные на первом устройстве
   - Передайте файл на второе устройство (email, облако, USB и т.д.)
   - Импортируйте файл на втором устройстве

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## 📖 Использование

1. **Добавление слов**: Нажмите "Добавить слово" и заполните форму
   - Польское слово (обязательно)
   - Русский перевод (обязательно)
   - Пример использования (опционально)
   - Категория (опционально)
   - Сложность (легко/средне/сложно)

2. **Изучение**: Нажмите "Начать изучение" для просмотра карточек
   - Кликните на карточку, чтобы перевернуть её
   - Отметьте сложность слова после просмотра
   - Переходите к следующей карточке

3. **Редактирование**: Нажмите на иконку редактирования рядом со словом

4. **Удаление**: Нажмите на иконку корзины рядом со словом

5. **Резервное копирование**: Используйте кнопки Экспорт/Импорт для сохранения данных

## 🛠 Технологии

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **Vite** - Сборщик и dev-сервер
- **Tailwind CSS** - Утилитарный CSS фреймворк для адаптивного дизайна
- **LocalStorage** - Хранение данных
- **PostCSS** - Обработка CSS
