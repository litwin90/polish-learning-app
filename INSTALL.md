# 📦 Установка и запуск

## Быстрый старт

1. **Установите зависимости:**
```bash
npm install
```

Это установит:
- React и React DOM
- TypeScript
- Vite
- Tailwind CSS и PostCSS
- Все необходимые зависимости

2. **Запустите приложение:**
```bash
npm run dev
```

3. **Откройте в браузере:**
Приложение будет доступно по адресу `http://localhost:5173`

## Мобильное использование

Приложение оптимизировано для мобильных устройств:

- **Адаптивный дизайн** - автоматически подстраивается под размер экрана
- **Touch-friendly** - большие кнопки и элементы управления
- **Оптимизированные карточки** - удобный размер для мобильных экранов
- **PWA-ready** - можно добавить на главный экран как приложение

### Добавление на главный экран (PWA)

1. Откройте приложение в мобильном браузере
2. В меню браузера выберите "Добавить на главный экран"
3. Приложение будет доступно как обычное приложение

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## Структура зависимостей

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **Vite** - Быстрый сборщик
- **Tailwind CSS** - Утилитарный CSS фреймворк
- **PostCSS** - Обработка CSS
- **Autoprefixer** - Автоматические префиксы для браузеров

## Решение проблем

### Ошибки при установке

Если возникают ошибки при `npm install`:
1. Убедитесь, что у вас установлен Node.js версии 18 или выше
2. Очистите кэш: `npm cache clean --force`
3. Удалите `node_modules` и `package-lock.json`, затем запустите `npm install` снова

### Проблемы с Tailwind

Если стили не применяются:
1. Убедитесь, что PostCSS настроен правильно (файл `postcss.config.js`)
2. Проверьте, что `tailwind.config.js` содержит правильные пути
3. Перезапустите dev-сервер
